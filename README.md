# Weather App

## Overview
This is a responsive Weather App built using HTML, CSS, and JavaScript. It fetches real-time weather data using the OpenWeatherMap API.

## Features
- Search weather by city
- Display temperature
- Display humidity
- Display wind speed
- Weather icons
- Saves last searched city using LocalStorage
- Responsive design
- SEO optimized
- Accessible interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
- OpenWeatherMap API
